# Uz3D AI Tutor — Chrome Extension (Manifest V3)

Ushbu kengaytma YouTube video sahifalaridan vaqt belgili subtitrlarni **faqat foydalanuvchi brauzerining o‘zida** o‘qib (server tomondan scraping qilmasdan), Uz3D AI Tutor platformasining `/api/generate-lesson` manziliga yuboradi.

## O‘rnatish tartibi (Developer Mode)
1. Google Chrome brauzerida `chrome://extensions` sahifasini oching.
2. O‘ng yuqori burchakda **Developer mode** tugmasini yoqing.
3. **Load unpacked** tugmasini bosing va loyihadagi `/chrome-extension` papkasini tanlang.
4. Kengaytma oynasida platforma manzilini kiriting (masalan, lokal muhitda `http://localhost:3000` yoki Vercel manzilingiz).
5. Istalgan YouTube dars videosini oching va pleyer ostidagi **Uz3D Doskada O‘rganish** tugmasini bosing.
